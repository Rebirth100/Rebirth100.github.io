一句话总结整章：指针就是一个专门用来存放地址的变量。

第 1 章 两个运算符：& 和 *

&：取地址

&a 读作”a 的地址”。打印地址时要用 %p，并且按标准写法转成 void*。

定义一个指针

p 是一个变量，它的值是 a 的地址。

*：解引用

*p 读作”p 指向的那个东西”。它是一个别名：*p 和 a 指的是同一块内存。

第 2 章 指针的类型为什么重要

既然指针只是存地址，那”地址”不就是个数字吗？为什么还要分 int *、char *、double *？

因为指针类型回答了两个问题：

  1. 解引用时读几个字节、怎么解释这些字节
  2. 做加减法时一步跨多远

指针 +1，跨过的是”一个它所指类型的对象”，不是 1 个字节。

这也是为什么 void *（通用指针）不能直接解引用、也不能做算术——它不知道自己指的东西有多大。

第 8 章 什么时候需要二级指针 **

规则和第 5 章一模一样：你想改谁，就传谁的地址。

  • 想改一个 int → 传 int *
  • 想改一个 int *（指针本身）→ 传 int **

如果写成 void alloc_it(int *p)，函数里改的只是拷贝，main 里的 p 依然是 NULL。

第 9 章 动态内存：指针真正的主战场

栈上的变量生命周期由作用域决定，堆上的由你决定。

几个要点：

  • malloc

    返回 void *，C 语言里不需要强制转换（C++ 才需要）。

  • 写 malloc(n * sizeof(int)) 比 malloc(n * 4) 好；更稳的写法是 malloc(n * sizeof *arr)，改类型时不用改这行。

  • calloc(n, size)

    会把内存清零；realloc 可以扩缩容。

  • 每一个 malloc 恰好对应一个 free。少了 → 内存泄漏；多了（重复 free）→ 未定义行为。

栈 vs 堆速查

谁分配 编译器 你

大小 编译期基本确定，容量小 运行期决定，容量大
能否返回地址给调用者 ❌ 不能 ✅ 能

错误 例子 后果

忘记 & scanf("%d", n); 崩溃（应为 &n）
返回局部变量地址 return &local; 悬垂指针

越界访问 a[n] （数组长 n） 覆盖相邻数据

修改字符串字面量 char *s="hi"; s[0]='H'; 崩溃
malloc 忘了检查 NULL p->x = 1; 内存不足时崩溃
