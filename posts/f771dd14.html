数组到底是什么

数组是 C 语言中用来存放多个同类型数据的一种结构。

这句话里有三个重点。

第一，数组能存多个数据。 第二，这些数据必须是同一种类型。 第三，数组中的数据在内存中是连续存放的。

数组为什么从 0 开始

很多人会疑惑：为什么数组第一个元素不是 scores[1]，而是 scores[0]？

一个简单的理解方式是：下标表示偏移量。

假设数组第一个元素的位置是起点。

scores[0] 表示从起点偏移 0 个元素，所以就是第一个元素。scores[1] 表示从起点偏移 1 个元素，所以是第二个元素。scores[2] 表示从起点偏移 2 个元素，所以是第三个元素。

C 语言非常接近底层，数组和内存地址关系很紧密。下标从 0 开始，计算地址时更直接。

数组的优点

数组最大的优点是能批量管理数据。

具体来说，有几个明显好处。

第一，代码更简洁。

不用定义大量变量，一个数组名就能管理一组数据。

第二，方便循环处理。

数组天然适合和 for 循环配合，输入、输出、求和、查找、排序都很方便。

第三，访问速度快。

数组元素连续存储，可以通过下标快速访问。

第四，结构清晰。

看到 scores[30]，就知道这是 30 个成绩；看到 temperatures[7]，就知道是一周温度。

第五，方便后续学习。

字符串、指针、函数参数、排序算法、数据结构，都会大量用到数组。

可以说，数组是从基础语法走向数据处理的第一道门。

数组的局限

数组很好用，但也不是万能的。

第一个局限：长度固定。

普通数组定义后，长度不能随便改变。

它就是 10 个元素。如果实际需要存 100 个，就不够了。

第二个局限：只能存同类型数据。

这个数组只能存整数，不能一会儿放整数，一会儿放小数，一会儿放字符串。

第三个局限：越界风险高。

C 语言不会总是主动帮你检查数组越界。写错下标可能破坏内存。

第四个局限：插入和删除不方便。

数组元素连续排列，如果要在中间插入一个元素，后面的元素可能都要移动。

这些局限并不代表数组不好。它只是说明，每种工具都有适合的场景。

数组适合存放数量相对固定、类型相同、需要快速访问的一组数据。

本章小结

数组用来保存一组相同类型的数据。

数组定义时要指定类型、名称和长度。

数组元素通过下标访问，下标从 0 开始。

长度为 n 的数组，合法下标是 0 到 n - 1。

数组在内存中连续存放，所以访问速度快，适合批量处理数据。

数组经常和循环配合使用，常见操作包括输入、输出、求和、求平均值、找最大值、找最小值。

局部数组没有初始化时，里面的值不可靠，建议养成初始化习惯。

数组越界是 C 语言中非常常见也非常危险的错误，写循环时尤其要注意边界。

当你发现自己在写很多个同类型变量时，通常就应该考虑使用数组。
