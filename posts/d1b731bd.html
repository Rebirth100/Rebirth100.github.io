C++增强特性与引用学习笔记

一、const 与枚举增强

1.1 C++基础通用增强回顾

增强点 C语言 C++
自定义类型使用 需struct/enum/union关键字 直接用类型名
全局变量 允许多次声明，一次初始化 不允许多次声明
布尔类型 无原生bool（非0为真） bool关键字，true/false
三目运算 返回值，不能当左值 返回变量引用，可当左值

1.2 枚举类型增强

C语言枚举的痛点

C语言枚举特点： - 本质是整形存储 - 所有枚举标识符全局有效 - 支持任意整形值直接赋值 - 易出现跨模块命名冲突

C++普通枚举（赋值约束增强）

C++普通枚举仅允许使用已声明的枚举标识符赋值，禁止直接传入任意整形值。

C++强类型枚举（enum class）

强类型枚举特点： - 语法：enum class 枚举名 { 标识符列表 }; - 仅需保证枚举类内部标识符不重复 - 调用必须通过 枚举类名::标识符 格式 - 彻底解决全局命名冲突问题 - 直接输出需强制类型转换

应用场景：QT框架中鼠标按键、键盘组合键等事件参数均采用枚举定义。

1.3 const 关键字增强

C语言const的缺陷

C语言中const常量本质是受访问权限限制的变量，可通过非const指针间接修改，安全性不足。

C++ const的存储逻辑

C++ const核心特性： - const常量默认存储于编译器符号表 - 直接调用标识符时始终访问符号表内的固定值，不可修改 - 对const常量取地址时，编译器在栈区开辟独立空间拷贝常量值 - 指针修改仅影响拷贝空间，不改变原常量值 - C++作为强类型安全语言，默认禁止将const常量直接赋值给普通指针

2.3 严格类型匹配校验

C++类型校验特点： - 强制校验函数返回值类型、参数列表与声明的一致性 - 类型不匹配直接触发编译错误 - C语言支持的整形等隐式兼容规则在C++中不生效 - 彻底解决C语言中函数地址赋值、参数传递依赖人工把控的问题

三、函数重载与内联函数

3.1 内联函数

适用场景

适用条件： - 代码行数不超过三五行 - 无复杂语法（if、for、switch等） - 会被频繁调用 - 典型应用：排序算法中频繁调用的swap函数

实现原理

内联函数在编译阶段直接将函数代码替换到所有调用位置，消除函数调用开销（栈申请、参数拷贝、返回地址保存等）。

使用限制

注意事项： - inline 关键字需同时在声明和定义阶段添加 - 仅单侧添加，编译器大概率拒绝内联 - 函数包含if、for、switch等复杂语法时，编译器大概率拒绝内联 - inline 只是建议，编译器有权拒绝

3.2 函数重载

核心概念

函数重载：参数列表不同、业务功能目标相同的同名函数。

重载判定规则

情况 是否构成重载
参数个数不同 是
参数类型不同 是
不同类型参数顺序不同 是
相同类型参数顺序不同 否
返回值类型不同 否

只有参数列表（个数、类型、顺序）可作为重载区分依据，返回值类型不同不算重载。

C与C++对比

C++匹配逻辑：根据调用时传入的参数类型、个数，自动匹配对应参数列表的重载函数，无需手动指定版本。

3.3 参数默认值

基本用法

语法约束

规则要点： - 默认值必须从参数列表最右侧向左连续设置，不可间断 - 参数默认值需在函数声明阶段定义 - 函数实现阶段无需重复设置默认值 - 调用时未传入对应参数则使用默认值，传入则以实际值为准

4.3 核心应用：自增自减运算符重载区分前后置

前后置区分规则： - 后置自增/自减：形参列表中添加 int 类型的无名称占位符 - 前置自增/自减：无需添加额外占位符 - 占位符参数在函数内部不使用，仅作为语法区分标识 - 同理适用于 -- 运算符

五、引用基础

5.1 引用的概念

引用是给已有变量起别名，与原变量完全等价，二者内存地址完全一致。

引用无需解引用语法，直接操作即可修改原变量。

5.2 引用的绑定规则

绑定规则： - 引用必须在声明的同时完成绑定 - 绑定后不可重新关联其他变量 - 后续对引用的赋值仅是对原变量的赋值操作

5.3 多层引用与右值引用

右值引用特点： - 使用 && 符号声明 - 仅可绑定常量、临时值等右值 - 无法绑定已初始化的左值变量 - 可作为函数重载的区分依据（区分左值、右值参数）

5.4 引用的本质

引用的底层实现是 int * const 类型的常指针：

特性 普通指针 int * 引用 int &
可修改指向 是 否（绑定后不可变）
可修改目标值 是 是
可为空 是 否
需要解引用 是（*p） 否（直接用）

引用本质是不能修改指向、但可间接修改目标空间值的常指针。

七、引用作为函数返回值

7.1 核心特性：函数表达式可作左值

引用作为函数返回值的核心作用：让函数表达式可以作为左值使用。

7.2 悬空引用风险

悬空引用成因： - 函数内部局部变量存储在栈空间 - 函数执行结束后栈空间自动回收 - 返回局部变量的引用后，引用关联的实际资源已消失 - 悬空引用不会在单次直接输出时必然报错，二次调用等操作时才大概率异常

7.3 合法实现：返回外部传入变量

返回引用时必须关联函数外部传入的变量（如参数、数组元素），不可返回函数内定义的局部变量。

八、扩展引用类型

8.1 指针的引用

指针本身是一类命名对象，普通变量支持被引用，指针同样支持被引用。

8.2 数组名的引用

数组引用参数的优势： - 减少函数调用时的数组指针拷贝 - 实现指针指向不可改、可间接修改元素值的效果 - 数组名本质是不得修改指向、但可间接修改元素值的特殊指针

8.3 常引用与常指针引用（面试题）

const位置不同，限定效果不同： - const int *：常指针，不能修改指向空间的值 - int * const：指针常量，不能修改指向 - const int * const：既不能改指向也不能改值

  2. 引用替换作业：将此前编写的所有函数、排序代码的指针及参数全部调整为引用类型，不可修改的参数使用常引用
