下标到底是什么

学习数组时，最容易让人不习惯的一点就是：数组不是从 1 开始数，而是从 0 开始数。

比如：

这个数组有 5 个元素，但它们的下标是：

很多初学者会下意识认为第一个元素应该是 scores[1]，第五个元素应该是 scores[5]。但在 C 语言中不是这样。

数组下标不是日常生活里的第几个，而是从数组起点开始偏移了几个位置。

这个理解非常关键。

scores[0] 的意思是：从数组开头出发，偏移 0 个元素，拿到第一个元素。scores[1] 的意思是：从数组开头出发，偏移 1 个元素，拿到第二个元素。scores[2] 的意思是：从数组开头出发，偏移 2 个元素，拿到第三个元素。

所以，下标更像偏移量，不是排名编号。

本章小结

数组下标从 0 开始，是因为下标本质上表示从数组起点出发的偏移量。

第一个元素偏移 0 个位置，所以是 arr[0]。

长度为 n 的数组，合法下标是 0 到 n - 1。

最后一个元素永远是 arr[len - 1]，不是 arr[len]。
