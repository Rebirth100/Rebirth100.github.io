一、第一个C++程序

1.1 C++与C语言的核心区别

维度 C语言 C++
编程范式 面向过程 面向对象
核心 函数设计与调用 类的设计与对象调用
兼容性 — 完全兼容C语言

cin 输入

二、C与C++典型区别

2.1 面向过程 vs 面向对象

面向过程（C语言）

核心思想：以函数设计为核心，沿业务流程依次调用函数。

特点： - 数据（结构体）和操作（函数）分离 - 开发核心是设计、调用函数 - 按业务流程一步步执行

面向对象（C++）

核心思想：以类的设计为核心，通过类实例化对象，调用对象的成员函数。

特点： - 数据和操作封装在一起（类） - 开发核心是设计类 - 类实例化出的对象是完整个体，包含数据和行为

2.2 核心区别对比

维度 面向过程（C） 面向对象（C++）
核心单位 函数 类
数据与操作 分离 封装在一起
调用方式 函数(数据) 对象.函数()
设计思路 按流程分步执行 先设计类，再实例化对象
实例化 定义结构体变量 定义类的对象

三、C++对C语言的增强

3.1 结构体/枚举/联合体类型使用增强

C语言写法

C++写法

C++中定义结构体、枚举、联合体后，类型名可直接使用，无需额外关键字。

3.2 全局变量声明规则差异

C语言规则

C语言特点： - 全局变量未手动初始化时，自动按类型赋默认值（int=0,指针=NULL等） - 允许多次声明（不带初始化） - 仅允许一次初始化

C++规则

C++特点： - 不允许全局变量多次声明 - 多次声明直接报重定义错误 - 语法检查更严格

3.3 新增布尔类型 bool

C语言（无原生布尔类型）

C++（原生bool关键字）

bool类型要点： - bool 是C++关键字 - 占 1字节 - false = 0，true = 1 - 按数值比较时，布尔会被向上转成整型

布尔类型比较注意事项

若直接将布尔值与整型比较，布尔会被向上转成整型，可能出现不符合预期的逻辑错误。建议统一为逻辑类型再比较。

3.4 三目运算符差异

C语言三目运算

C++三目运算

注意： - C++三目运算返回的是变量本身（引用），可作左值 - 仅支持可修改的变量，不能是常量或表达式 - 这引出了C++的引用概念

3.5 C++增强特性汇总

增强点 C语言 C++
结构体使用 需struct关键字或typedef 直接用类型名
枚举使用 需enum关键字 直接用类型名
联合体使用 需union关键字 直接用类型名
全局变量 允许多次声明，一次初始化 不允许多次声明
布尔类型 无原生bool（C99需stdbool.h） bool关键字，1字节
三目运算 返回值，不能当左值 返回变量引用，可当左值
结构体函数 不支持（需函数指针模拟） 直接支持成员函数
输入输出 printf/scanf（需格式符） cout/cin（自动识别类型）

四、课程作业

作业一：车机状态上报全链路流程图

绘制车机状态上报项目的业务流程图，覆盖： - 车机端构建JSON数据 - UDP发送到服务端 - 服务端解析JSON - 存入数据库 - 服务端回复确认 - 车机端更新本地状态

标注各环节使用的技术点（CJSON、UDP、SQLite、信号驱动IO等）。

作业二：Linux全阶段思维导图整合

将Linux整个阶段的零散思维导图合并为完整的一份，涵盖： - Linux基础命令 - 文件管理、用户权限 - 磁盘管理、Makefile、静态库 - C语言文件操作、链表模块 - 系统IO、目录操作 - 进程、守护进程、进程间通信 - 信号、共享内存 - 物联网项目架构、SQLite、JSON、UDP通信
