C++-3.C++面向对象与内存管理学习笔记

rebirth1002026-08-222026-10-06

C++面向对象与内存管理学习笔记

一、常引用与指针引用

1.1 引用核心特性回顾

特性 说明
本质 已有变量标识符的别名
内存开销 无需开辟新内存空间，无额外开销
与指针差异 指针是独立变量需存地址，引用仅为别名
初始化 声明时必须直接初始化
绑定后 不可修改指向，等价于不可改指向的常指针
函数参数 可实现与指针一致的间接访问，减少参数拷贝，效率更高
函数返回值 可让函数表达式作为左值使用

1.2 常引用（const引用）

基本规则

常引用绑定规则： - const修饰的常量仅能通过同类型常引用关联 - 普通引用无法绑定常量（避免通过引用修改常量） - 普通可修改变量可被常引用绑定（权限收缩，安全操作）

常引用的核心应用场景

常引用三大应用场景： 1. 只读权限限制：对普通变量的引用增加const修饰，限制仅能读取 2. 字面量直接关联：可直接绑定数字、临时构造的匿名对象等字面量 3. 函数传参优化：仅需读取参数的函数使用常引用，避免复杂类型拷贝开销，同时支持临时对象直接传参

特殊场景注意事项

当常引用绑定右值字面量时，若发生强制类型转换可能生成新的临时变量，需避免此类写法引发逻辑异常。

1.3 指针引用

基本概念

指针引用特点： - 指针作为独立变量可被引用 - 指针引用的使用逻辑与原指针完全一致 - 无需额外增加间接访问层级 - 不是指针的指针（int **），引用仅为原变量的别名

指针引用的应用场景

指针引用可替代二级指针（int **），语法更简洁，直接修改传入指针的指向。

1.4 多层级const约束规则

const位置与约束范围

写法 能否修改指向 能否修改指向的值
int * 能 能
const int * 能 不能
int * const 不能 能
const int * const 不能 不能

引用的安全校验规则

引用安全校验规则： - 引用仅支持权限完全一致或权限收缩的绑定操作 - 禁止将高权限引用绑定到低权限的原变量上 - C语言指针无权限校验逻辑，只要地址合法即可操作 - 引用的安全约束可提前拦截非法操作，避免运行时异常

二、面向对象概念与class/struct

2.1 面向对象三大特性

所有面向对象编程体系均遵循三大语法特性：

特性 说明
封装 把数据和针对该数据的相关操作整合为一体，形成类
继承 子类继承父类的属性和行为，实现代码复用
多态 同一接口不同实现，根据对象类型调用对应方法

2.2 封装的核心概念

封装的定义：将数据与对应操作封装为一体形成类，实现将物理概念转换为计算机可识别的表示形式。

类的组成： - 成员变量：对应对象的静态属性 - 成员函数：对应对象的动态行为

2.3 this指针

this指针特点： - 类的成员函数内部默认内置，无需手动定义 - 用于区分当前对象自身数据与外部传入数据 - 无成员变量的类也存在this指针 - 该特性是C语言不具备的

2.4 访问属性

访问属性 类内部 类外部 子类内部
private 能 不能 不能
public 能 能 能
protected 能 不能 能

访问属性的作用：支持通过设置成员访问属性，对类的内部实现细节进行选择性隐藏，仅开放指定内容供外部调用。

2.5 class与struct的区别

class与struct的唯一区别： - struct成员默认公有（public） - class成员默认私有（private） - 二者实现类的底层逻辑完全一致 - 均可手动修改访问属性

将struct改为class后，类的成员会被默认隐藏，这是二者最直观的差异。

三、对象的生命周期

3.1 资源获取即初始化（RAII）

C++面向对象的核心设计准则：对象实例化时同步完成资源获取与合法初始化，避免出现非法数据。

3.2 构造函数

基本定义

构造函数特点： - 与类名完全同名 - 无返回值（不能写void） - 仅能作为类的成员函数 - 对象实例化时由编译器自动调用 - 用于完成对象数据的正确初始化

构造函数重载

构造函数分类： - 无参构造：无入参的构造函数 - 有参构造：携带指定类型入参的构造函数 - 二者可同时存在，实例化时根据参数自动匹配

默认构造函数

默认构造函数规则： - 开发者未自定义任何构造函数时，编译器自动生成无参默认构造 - 默认构造仅完成对象内存分配，不做数据校验 - 只要自定义任意版本构造函数，编译器默认无参构造就会被隐藏 - C++新语法支持显式声明调用默认构造或禁用指定构造

3.3 析构函数

析构函数特点： - 类名前添加~符号 - 无返回值、无参数 - 对象销毁前由编译器自动调用 - 负责对象资源清理工作 - 不支持重载（所有对象销毁的清理逻辑统一）

3.4 对象生命周期与栈顺序

对象生命周期规则： - 完整生命周期从构造函数执行启动，到析构函数执行完成后正式销毁 - 栈对象严格遵循先构造后析构、后构造先析构的规则 - 与函数栈帧的入栈、出栈逻辑完全匹配 - 函数退出前自动完成栈内所有对象的析构操作

3.5 拷贝构造函数

拷贝构造函数特点： - 以同类对象的const引用作为唯一入参 - 基于已有对象的所有属性，生成属性完全一致的新对象

三大触发场景： 1. 同类对象直接赋值初始化：Person p2 = p1; 2. 函数传参为对象类型（值传递） 3. 函数返回值为对象类型（值返回）

3.6 移动构造函数

移动构造函数特点： - 以同类对象的右值引用（&&）作为入参 - 针对临时对象的资源直接转移所有权，无需额外拷贝数据 - 移动操作完成后需将原临时对象的指针成员置空 - 临时对象本身不会被后续代码使用，直接转移资源可省去拷贝开销

四、深拷贝与浅拷贝

4.1 浅拷贝的固有缺陷

浅拷贝的问题： - 编译器默认提供的拷贝构造、赋值运算符重载均为浅拷贝 - 仅复制成员变量原始值（指针的值，即地址） - 导致多个对象的指针指向同一块堆内存 - 多个对象生命周期结束时，对同一块堆内存重复调用free，直接引发程序崩溃

4.2 深拷贝的实现

深拷贝实现要求： - 类包含指针成员时必须自定义深拷贝构造函数 - 为新对象的指针成员单独申请独立堆空间 - 再将原对象对应内容复制到新空间 - 若业务场景明确要求多个对象指向同一块堆内存，可无需实现深拷贝

4.3 深赋值（赋值运算符重载）

深赋值实现要求： - 自定义赋值运算符重载时，先释放当前对象已持有的旧堆内存 - 再执行与深拷贝一致的内存申请与内容复制操作 - 返回*this支持连续赋值 - 需判断自赋值（this == &other）避免释放后访问已释放内存

4.4 构造函数初始化列表

初始化列表规则： - 仅类的构造函数支持使用初始化列表语法 - 执行优先级高于构造函数内部的代码逻辑 - const修饰的成员变量、引用成员、继承场景下的父类对象，必须通过初始化列表完成初始化 - 普通成员变量也可在初始化列表中初始化

五、移动语义

5.1 移动语义基础逻辑

移动语义特点： - 针对右值引用类型的临时对象 - 通过移动构造、移动赋值操作直接转移其堆内存所有权 - 无需重复申请新的堆内存空间 - 移动操作完成后需将原临时对象的指针成员置空 - 避免原对象析构时重复释放已被转移所有权的堆内存

5.2 移动语义的核心优势

操作 深拷贝 移动语义
内存申请 需要为新对象申请独立堆空间 不需要，直接转移所有权
数据复制 需要将原对象内容复制到新空间 不需要，直接复用原空间
原对象状态 原对象保持不变 原对象指针置空，资源被转移
适用场景 左值对象（后续还要使用） 右值临时对象（后续不再使用）
效率 较低（有额外申请和拷贝开销） 较高（直接转移，无额外开销）

相比深拷贝需要额外申请、拷贝堆内存的操作，移动操作直接转移内存所有权，可大幅提升对象拷贝、赋值场景的执行效率。

5.3 移动语义与noexcept

noexcept的作用： - 声明函数不会抛出异常 - 符合C++标准委员会的规范要求 - 可避免异常相关的编译报错 - STL容器（如vector）在扩容时，只有移动构造声明了noexcept才会调用移动构造，否则会调用拷贝构造

六、核心概念速查表

概念 关键字/语法 核心说明
常引用 const T & 只读引用，可绑定常量和字面量
指针引用 T * & 指针的别名，可修改指针指向
常指针 const T * 不能修改指向的值，可改指向
指针常量 T * const 不能改指向，可修改指向的值
封装 class/struct 数据与操作整合为一体
this指针 this 成员函数内置，指向当前对象
访问属性 private/public/protected 控制成员访问范围
构造函数 类名() 实例化时自动调用，初始化对象
析构函数 ~类名() 销毁前自动调用，清理资源
拷贝构造 类名(const 类名 &) 用已有对象创建新对象
移动构造 类名(类名 &&) 转移临时对象资源所有权
深拷贝 自定义拷贝构造 为指针成员申请独立空间
浅拷贝 编译器默认 仅复制指针值，指向同一块内存
初始化列表 构造函数() : 成员(值) {} 构造函数专用，优先级高
移动赋值 operator=(类名 &&) 转移右值对象资源
noexcept noexcept 声明函数不抛异常

七、面试高频考点

  1. 深拷贝与浅拷贝的区别：浅拷贝仅复制指针值导致多个对象指向同一块内存，析构时重复释放崩溃；深拷贝为新对象申请独立空间并复制内容
  2. 什么时候需要自定义拷贝构造：类包含指针类型成员变量且指向堆内存时
  3. 构造函数初始化列表的作用：初始化const成员、引用成员、父类对象，执行优先级高于构造函数体
  4. 移动语义的原理和优势：针对右值临时对象直接转移资源所有权，无需额外申请和拷贝，提升效率
  5. class与struct的区别：默认访问属性不同（class默认private，struct默认public）
  6. this指针的作用：区分成员变量与参数，指向当前对象
  7. 析构函数的作用和特点：释放堆内存等资源，无参数不支持重载，对象销毁前自动调用
  8. 拷贝构造的触发场景：同类对象赋值初始化、函数值传递、函数值返回
