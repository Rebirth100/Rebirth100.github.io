物联网项目架构与车机管理系统学习笔记

一、常见物联网项目架构

1.1 典型电动车物联网系统结构

1.2 各模块职责

模块 职责
用户APP 注册登录、查看车辆状态、远程控制、接收推送通知
车机服务器 提供网络服务（TCP/UDP/HTTP）、与数据库交互、数据中转
数据库 存储用户信息、车辆信息、上报数据、业务轨迹
物联网终端 采集车辆状态（GPS、地址、时间）、上报数据、接收下发指令
车机管理系统 维护车辆信息、初始化数据库、后台管理

1.3 核心设计原则

  • 数据是项目核心：数据库不直接对外开放，通过服务器间接访问
  • 前后端分离：前端负责展示，后端通过统一数据格式（JSON）与前端交互
  • 统一数据操作语言：所有模块通过SQL语句操作数据库
  • 安全防护：防火墙、身份验证、人机检测等

1.4 通信协议选择

场景 协议 原因
车辆位置定时上报 UDP 频繁、短消息、允许少量丢失
OTA固件升级 TCP 长连接、数据完整性要求高
Web页面访问 HTTP 支持网页、标准化
APP与服务器交互 TCP/HTTP 可靠传输、请求响应模式

五、JSON操作（CJSON库）

5.1 JSON基础

JSON（JavaScript Object Notation）是一种轻量级数据交换格式，本质是纯字符串。

合法JSON文档只有三种： 1. 对象：{ } 大括号包裹 2. 数组：[ ] 中括号包裹 3. 空内容

不能用双引号开头，那是非法结构。

5.2 JSON结构规则

规则要点 - 对象用 {}，键值对用 键:值，键必须用双引号 - 数组用 []，元素用逗号分隔 - 最后一个键值对/元素不能加逗号 - 值类型：字符串（双引号）、数值（无引号）、布尔（true/false，小写）、数组、对象、null

5.3 CJSON库选型与集成

版本 特点
CJSON 1.6 需自行编译
CJSON 1.7 无需额外编译，直接复制文件使用

集成步骤 1. 从开源平台获取 cJSON 1.7 源码 2. 复制 cJSON.c 和 cJSON.h 到项目目录 3. 编译时一起编译即可

面试提及CJSON时需明确版本号，说明版本差异。

5.6 JSON在项目中的作用

JSON的核心价值 - 统一数据格式：APP、终端、Web、小程序都用JSON交互 - 跨平台兼容：纯字符串，任何系统/语言都能解析 - 前后端解耦：前端只关心JSON格式，不关心后端实现

六、综合开发要点

6.1 开发效率原则

  • 优先使用成熟第三方库：SQLite（数据库）、CJSON（JSON）、CURL（网络），不重复造轮子
  • 结构化数据用数据库：车辆信息、用户信息等
  • 中间传输数据用JSON：网络通信、前后端交互
  • 复用已有代码：链表模块、菜单结构等可直接复用

6.2 面试准备要点

  • 项目中使用的库需明确版本号（如CJSON 1.7、SQLite3）
  • 熟悉项目遵循的国标/行业标准（如车架号22位、国五/国六排放标准）
  • 能说清各模块职责和数据流向
  • 数据库表设计思路和字段含义
